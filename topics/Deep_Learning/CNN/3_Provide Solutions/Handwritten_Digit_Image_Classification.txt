HANDWRITTEN DIGIT CLASSIFICATION USING A NEURAL NETWORK

Scenario
An educational application needs to recognize a handwritten digit from its
image. As a student data scientist, build a neural network that learns from
labeled examples and predicts which digit, from 0 to 9, appears in an unseen
image. Use the supplied solved notebook as the reference implementation.

Objective
Develop and evaluate a ten-class handwritten digit classifier. Compare a
network with no hidden layers against a network with one hidden layer.
Explain normalization, flattening, output scores, and the interpretation
of a confusion matrix. This exercise uses fully connected neural networks;
the reference notebook does not use convolution or pooling layers.

Reference notebook
digits_recognition_neural_network.ipynb (in this same folder).

Dataset
Use MNIST through keras.datasets.mnist.load_data(), as in the notebook.
It provides 60,000 training images and 10,000 test images. Each image is a
28 x 28 grayscale image, initially with pixel values from 0 to 255.
Each label is an integer representing the digit shown in the image.

Class labels
0 - Digit zero
1 - Digit one
2 - Digit two
3 - Digit three
4 - Digit four
5 - Digit five
6 - Digit six
7 - Digit seven
8 - Digit eight
9 - Digit nine

Student tasks
1. Load the dataset using TensorFlow/Keras. Report the number of training
   and test images, image and label shapes, pixel range, and class counts.
   Display sample images with their actual digit labels.
2. Divide pixel values by 255 to normalize them to the range 0 to 1.
   Explain why the same preprocessing must be applied to training and
   test images.
3. Reshape each image into a vector of 784 values. Report the flattened
   training and test shapes and explain how 28 x 28 becomes 784 inputs.
4. Reproduce the baseline network: a Dense layer with ten output neurons,
   sigmoid activation, and input shape (784,), with no hidden layer.
   Compile with Adam, sparse categorical cross-entropy, and accuracy.
   Train for five epochs, as in the reference notebook.
5. Predict scores for test images. Display one image and its ten output
   scores. Use numpy.argmax to obtain its predicted digit and compare
   the prediction with its actual label.
6. Convert the predictions into digit labels and create a 10 x 10 confusion
   matrix using actual labels as rows and predicted labels as columns.
   Plot a labeled heatmap and explain the diagonal and off-diagonal cells.
7. Reproduce the second network: Dense(100) with ReLU, followed by Dense(10)
   with sigmoid. Use the same optimizer, loss, and five-epoch training
   duration. Compare its results with the baseline without assuming that
   the hidden layer will always improve performance.
8. Reproduce the third network: Flatten with input shape (28, 28), followed
   by Dense(100, ReLU) and Dense(10, sigmoid). Pass normalized images
   directly instead of manually flattened vectors. Train for ten epochs,
   as in the notebook, and report its evaluation results.
9. Explain why the third experiment changes both flattening implementation
   and training duration. Repeat the two hidden-layer versions with the
   same epoch count and settings to make a fair comparison.
10. Display at least ten test images with actual digits, predicted digits,
    and highest output scores. Include incorrect predictions when available
    and discuss the digit pairs the model confuses most often.
11. Allow a user to choose a test-image index. Show the selected image,
    predicted digit, actual digit, and scores for all ten classes. Check
    that the chosen index is within the available range.

Evaluation guidance
The reference notebook evaluates each example model on the supplied test
set. For a comparison used to choose a final model, reserve a validation
subset from the training data and keep the test set for final evaluation.
Use a fixed random seed, the same data splits, and comparable training
settings. Plot training and validation accuracy and loss. Report accuracy,
per-class precision, recall, F1-score, and a labeled confusion matrix for
the selected model. Report observed results without an accuracy target.

Output activation note
The reference notebook uses sigmoid in all three output layers. Its ten
raw sigmoid outputs are independent scores and need not sum to 1; do not
present them as a normalized probability distribution over the digits.
For ten mutually exclusive classes, also try a ten-neuron softmax output
with sparse categorical cross-entropy. Explain why softmax is the usual
choice, check that its outputs sum to 1, and compare validation results.
Use integer labels with this loss; one-hot encoding is not required.

Questions to answer
- Why does a flattened image contain 784 values?
- Why are there ten output neurons?
- What does numpy.argmax return, and why does that index represent a digit?
- What does the hidden layer add to the baseline model?
- How do ReLU, sigmoid, and softmax differ in this exercise?
- Why is a high output score not proof that a prediction is correct?
- Does Flatten have trainable weights or change the pixel values?
- Why does a ten-epoch result not isolate the benefit of a hidden layer
  when the comparison model was trained for only five epochs?
- Which digits are confused most often in your confusion matrix?
- Why might a model trained on MNIST fail on a phone photograph of a digit?

Expected submission
A Jupyter notebook with dataset inspection, labeled sample images,
normalization and flattening, the three reference model implementations,
executed outputs, training plots, fair model comparisons, final evaluation,
confusion matrices, interactive index selection, and answers to the
questions. Record model settings and measured results. Explain limitations
and propose one improvement.

Optional challenge
Accept a separate image containing a single handwritten digit. Convert it
to grayscale, crop and center the digit, resize it to 28 x 28, match the
foreground/background convention used by MNIST, and normalize its pixels.
Display the processed image before predicting. Discuss how handwriting,
background, centering, and preprocessing affect the prediction. Such an
image is not guaranteed to be recognized correctly.
